## 一、项目概览

### 1.1 产品定位

一款**纯本地、零依赖**的浏览器插件，帮助用户高效管理、分类、搜索和复用 AI 提示词（Prompt）。数据完全存储在本地，保护隐私，支持跨设备迁移导入导出。

### 1.2 核心价值主张

| 痛点 | 解决方案 |
|------|----------|
| 提示词散落各处，难以找到 | 统一管理 + 全文搜索 |
| 优质 Prompt 无法复用 | 一键复制 + 标签分类 |
| 换设备数据丢失 | JSON/CSV 导入导出 |
| Prompt 越来越多难以整理 | 分类树 + 颜色标签 |

### 1.3 功能全景（来自导图）


## 二、技术选型

### 2.1 技术栈

| 层级 | 技术 | 理由 |
|------|------|------|
| 插件框架 | Chrome Extension Manifest V3 | 兼容 Chrome/Edge，现代标准 |
| 前端框架 | **Vue 3 + Composition API** | 轻量响应式，适合插件体积限制 |
| UI 组件库 | **Element Plus（按需引入）** | 成熟、主题定制灵活 |
| 构建工具 | **Vite + vite-plugin-web-extension** | 极速热更新，插件开发首选 |
| 状态管理 | **Pinia** | Vue 3 官方推荐，轻量 |
| 本地存储 | **IndexedDB（via Dexie.js）** | 支持大量 Prompt，复杂查询 |
| 搜索引擎 | **MiniSearch** | 纯 JS 全文索引，零服务器依赖 |
| Markdown 渲染 | **marked + DOMPurify** | 安全渲染，轻量 |
| 样式 | **UnoCSS（原子化）** | 极致体积，支持暗色模式 |
| 测试 | **Vitest + Playwright** | 单元测试 + E2E |

## 三、数据结构设计

### 3.1 核心数据模型

```typescript
// ============ Prompt 提示词 ============
interface Prompt {
  id: string;           // UUID
  title: string;        // 标题（必填，最长 100 字）
  content: string;      // 正文（支持 Markdown）
  categoryId: string;   // 所属分类 ID
  tags: string[];       // 标签数组
  isFavorite: boolean;  // 是否收藏
  isPinned: boolean;    // 是否置顶
  useCount: number;     // 使用次数
  createdAt: number;    // 创建时间戳
  updatedAt: number;    // 更新时间戳
  lastUsedAt: number;   // 最近使用时间戳
}

// ============ Category 分类 ============
interface Category {
  id: string;
  name: string;         // 分类名称
  icon: string;         // emoji 或图标名
  color: string;        // HEX 颜色值
  sortOrder: number;    // 排序权重
  parentId?: string;    // 父分类（支持二级分类）
  createdAt: number;
}

// ============ 内置虚拟分类（不存 DB）============
const BUILT_IN_CATEGORIES = [
  { id: '__all__',      name: '全部',     icon: '📋' },
  { id: '__favorite__', name: '收藏',     icon: '⭐' },
  { id: '__recent__',   name: '最近使用', icon: '🕐' },
]

// ============ Setting 设置 ============
interface Setting {
  key: string;
  value: unknown;
}
// 常用 key:
// theme: 'light' | 'dark' | 'system'
// viewMode: 'list' | 'card'
// fontSize: 'sm' | 'md' | 'lg'
// displayMode: 'compact' | 'normal' | 'fullscreen'
```

### 3.2 Dexie 数据库定义

```typescript
// db/schema.ts
import Dexie, { Table } from 'dexie'
import type { Prompt, Category, Setting } from '../types'

class PromptDB extends Dexie {
  prompts!: Table<Prompt>
  categories!: Table<Category>
  settings!: Table<Setting>

  constructor() {
    super('PromptManagerDB')
    this.version(1).stores({
      prompts: '++id, title, categoryId, *tags, isFavorite, isPinned, useCount, updatedAt, lastUsedAt',
      categories: '++id, name, sortOrder, parentId',
      settings: 'key',
    })
  }
}

export const db = new PromptDB()
```

## 四、核心功能设计（Phase 1 · MVP）

### 4.1 提示词 CRUD

#### 新增/编辑 Prompt

- 表单字段：标题（必填）、分类（下拉）、标签（输入框 Enter 确认）、内容（富文本/Markdown）
- 编辑/预览双模式切换（Tab 切换，快捷键 `Ctrl+P`）
- 自动保存草稿（Debounce 1s 写入 `localStorage`）
- 保存时更新 `updatedAt`，首次保存设 `createdAt`

#### 一键复制

```typescript
// composables/useClipboard.ts
export function useClipboard() {
  const copy = async (text: string, promptId?: string) => {
    await navigator.clipboard.writeText(text)
    if (promptId) {
      await db.prompts.update(promptId, {
        useCount: (await db.prompts.get(promptId))!.useCount + 1,
        lastUsedAt: Date.now()
      })
    }
    showToast('已复制到剪贴板 ✓')
  }
  return { copy }
}
```

#### 删除策略

- 单条删除：二次确认弹窗
- 批量删除：勾选模式 → 底部操作栏 → 确认删除
- **软删除**（可选）：增加 `deletedAt` 字段，30 天后自动清理

### 4.3 导入/导出（Phase 1 核心）

#### 导出流程

```typescript
// composables/useImportExport.ts

// 导出 JSON
async function exportJSON(options?: { categoryIds?: string[] }) {
  const prompts = options?.categoryIds
    ? await db.prompts.where('categoryId').anyOf(options.categoryIds).toArray()
    : await db.prompts.toArray()
  const categories = await db.categories.toArray()
  const data = { version: '1.0', exportedAt: Date.now(), categories, prompts }
  downloadFile(JSON.stringify(data, null, 2), 'prompts-backup.json', 'application/json')
}

// 导出 Markdown
async function exportMarkdown() {
  const categories = await db.categories.toArray()
  const prompts = await db.prompts.toArray()
  let md = '# Prompt 备份\n\n'
  for (const cat of categories) {
    md += `## ${cat.icon} ${cat.name}\n\n`
    const catPrompts = prompts.filter(p => p.categoryId === cat.id)
    for (const p of catPrompts) {
      md += `### ${p.title}\n\n${p.content}\n\n---\n\n`
    }
  }
  downloadFile(md, 'prompts-backup.md', 'text/markdown')
}

// 导出 CSV
async function exportCSV() {
  const prompts = await db.prompts.toArray()
  const header = ['id', 'title', 'content', 'categoryId', 'tags', 'isFavorite', 'createdAt']
  const rows = prompts.map(p => [
    p.id, p.title,
    `"${p.content.replace(/"/g, '""')}"`,
    p.categoryId, p.tags.join('|'), p.isFavorite,
    new Date(p.createdAt).toISOString()
  ])
  downloadFile([header, ...rows].map(r => r.join(',')).join('\n'), 'prompts.csv', 'text/csv')
}
```

#### 导入冲突解决策略

```typescript
type ConflictStrategy = 'replace' | 'skip' | 'merge'

async function importJSON(file: File, strategy: ConflictStrategy = 'skip') {
  const raw = JSON.parse(await file.text())
  const { prompts, categories } = raw

  for (const cat of categories) {
    const existing = await db.categories.get(cat.id)
    if (existing) {
      if (strategy === 'replace') await db.categories.put(cat)
      else if (strategy === 'merge') await db.categories.put({ ...existing, ...cat, id: existing.id })
      // skip: 跳过
    } else {
      await db.categories.add(cat)
    }
  }

  for (const prompt of prompts) {
    const existing = await db.prompts.get(prompt.id)
    if (existing) {
      if (strategy === 'replace') await db.prompts.put(prompt)
      else if (strategy === 'merge') await db.prompts.put({ ...existing, ...prompt, id: existing.id })
    } else {
      await db.prompts.add(prompt)
    }
  }
}
```

### 4.4 全文搜索

```typescript
// composables/useSearch.ts
import MiniSearch from 'minisearch'

const miniSearch = new MiniSearch({
  fields: ['title', 'content', 'tags'],
  storeFields: ['id', 'title'],
  searchOptions: {
    boost: { title: 3, tags: 2, content: 1 },
    fuzzy: 0.2,
    prefix: true,
  }
})

export async function buildSearchIndex() {
  const all = await db.prompts.toArray()
  miniSearch.removeAll()
  miniSearch.addAll(all.map(p => ({
    id: p.id, title: p.title,
    content: p.content, tags: p.tags.join(' '),
  })))
}

export function searchPrompts(query: string) {
  return miniSearch.search(query)
}
```

## 八、风险与注意事项

| 风险 | 等级 | 应对策略 |
|------|------|----------|
| IndexedDB 容量限制 | 低 | 浏览器默认分配 >= 10GB，足够使用 |
| MV3 Service Worker 随时被终止 | 中 | 不在 SW 存状态，全部走 IndexedDB |
| 大量数据时搜索索引内存占用 | 中 | 超过 5000 条时使用 Dexie 原生查询兜底 |
| 导入时数据格式不兼容 | 低 | 严格 JSON Schema 校验 + 友好错误提示 |
| 浏览器卸载插件导致数据丢失 | 高 | **首次使用时强引导用户导出备份** |
