Core Features
🌐

Playwright 全量采集

全页截图 + 视口截图 + 组件级截图，Shadow DOM 穿透、交互状态追踪，649KB+ 丰富 DSL 原始数据。

⚙️

Spec Compiler 零损耗编译

将原始 DSL 编译为结构化 Design Specification，程序化提取 links/images/headings，保留完整 HTML 片段，零数据损耗。

📦

多格式导出

HTML 样例、Design Tokens JSON、CSS/Tailwind 配置、Storybook Stories，每种格式独立 Exporter 可插拔。

🤖

AI IDE 友好导出

一键生成 .trae/rules、.cursorrules、CLAUDE.md、AGENTS.md 规则文件，AI IDE 自动按设计系统开发。

🎨

Design Tokens 提取

颜色、排版、间距、圆角、阴影、断点六大令牌类型，Style Dictionary 兼容，可转 CSS/iOS/Android。

☁️

WebDAV / Gitee 云同步

支持坚果云、Nextcloud、Seafile 等 WebDAV 服务及 Gitee 仓库双向同步，凭证持久化到磁盘。

🔌

MCP 协议支持

Model Context Protocol 进程管理，支持 VS Code、Cursor、Windsurf、Claude Desktop 等 IDE 接入。

📋

设计规范浏览器

六 Tab 浏览（品牌/令牌/组件/截图/指南/导出），ComponentCard 截图 + 内容预览 + 可折叠 HTML/样式。

🔒

全栈 TypeScript + TDD

Node.js + React 全栈 TypeScript，51+ 单元测试用例，vitest TDD 开发，CI/CD 完整流水线。

Tech Stack
Node.js TypeScript Express React Vite Playwright Tailwind CSS Zustand Vitest Docker
