Core Features
📡

多源 RSS 自动抓取

内置东方财富、华尔街见闻、中新财经、36氪四大源，CORS 代理三级降级策略，支持自定义添加。

✍️

发稿后台管理

手动发稿、Markdown/TXT/JSON 文档批量导入、草稿队列管理，密码保护安全入口。

🔍

全文搜索与筛选

标题+摘要+来源全文检索，按标签、订阅源、状态多维筛选，毫秒级响应。

💾

IndexedDB 持久化

所有文章与配置本地持久存储，Dexie.js 驱动，零云端依赖，刷新不丢失。

📊

行情数据条

上证指数、深证成指、沪深300、创业板指、纳斯达克、BTC 实时模拟，5秒自动刷新。

🌙

深蓝夜色终端

深蓝底色 + 琥珀金强调色，致敬彭博终端 / Palantir 风格，专业财经视觉体验。

🏷️

标签聚合与分类

公告/研报/监管/市场分类筛选，标签云聚合页，一键定位关联资讯。

📱

响应式移动适配

桌面与移动端自适应布局，底部 Tab 导航，触摸手势支持，随时随地查阅。

🔒

纯前端零后端

Vue 3 SPA，全部数据存储在浏览器本地，无需服务器，无数据上传，隐私绝对安全。

Tech Stack
Vue 3 Vite Pinia Vue Router Dexie.js IndexedDB Hash Router CORS Proxy
