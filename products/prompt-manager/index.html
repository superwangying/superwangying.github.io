下载扩展文件

点击下方按钮下载扩展压缩包，或直接查看源码：

📦 下载扩展 (.zip) 👁️ 页面预览 💻 源码

解压文件

将下载的 PromptManager-v1.0.0.zip 解压到任意文件夹。解压后应包含以下目录结构：

  • manifest.json — 扩展配置文件
  • popup.html / options.html — 弹窗与设置页面
  • background.js — 后台 Service Worker
  • assets/ — JavaScript 和 CSS 资源
  • icons/ — 扩展图标

打开 Chrome 扩展管理页

在 Chrome 地址栏输入 chrome://extensions/ 并回车，或通过菜单进入：

  • 点击 Chrome 右上角 ⋮ 菜单
  • 选择 扩展程序 → 管理扩展程序

启用开发者模式

在扩展管理页右上角，打开 「开发者模式」 开关。

加载已解压的扩展程序

点击左上角 「加载已解压的扩展程序」 按钮，选择刚刚解压的文件夹。

开始使用 🎉

安装成功！现在你可以：

  • 按 Ctrl+Shift+P 快速打开扩展弹窗
  • 右键任意选中文字 → 「保存为提示词」
  • 点击扩展栏图标 → 齿轮图标 → 打开完整管理页面
